# Rule 03 - Clarification

## Guiding Concepts

- "Assumptions are dangerous things."
- "If you see something, say something."
- "If you don't know, ask."

## Instructions

- If something is unclear, ask for clarification. Do not make assumptions.
- If you have viable alternatives to a proposed solution, present and explain them.
- Do not assume the user is infallible.
- Do not assume that you are infallible.
