# Rule 05 - Browser Testing

## Guiding Concepts

- "The fastest check is the one you don't have to run."

## Instructions

- Do not launch a browser or a dev server to verify front-end changes. The user verifies these manually.
- Make the change, then stop. State plainly what was changed and what is left unverified.
- Only perform browser testing when the user indicates that a previous pass was not correct.
- Static checks that need no browser, such as type checking and linting, are still expected.
