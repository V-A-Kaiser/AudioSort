# Rules

- The rule number of a rule is determined by the numerical prefix in the filename: 01_file.md is rule #01, 02_anotherfile.md is rule #02.
- Rules should be prioritized in the ascending order: rule #1 has a higher priority than rule #2.
- If two or more rules conflict, the highest priority rule 'wins'.
